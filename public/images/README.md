## 图片来源建议

你可以从以下渠道获取图片：

1. **自己拍摄** - 如果你去过这些景点
2. **Unsplash** - https://unsplash.com (搜索相关关键词，免费商用)
3. **Pixabay** - https://pixabay.com (免费图片)
4. **维基百科** - 相关词条下的图片(注意版权)

## 图片要求

- 格式：JPG 或 PNG
- 建议尺寸：宽度至少 800 像素
- 文件大小：每张不超过 500KB
- 命名：必须与上述文件名完全一致（区分大小写）
