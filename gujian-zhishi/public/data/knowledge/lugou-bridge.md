# 卢沟桥

- ID: lugou-bridge
- 英文名: Lugou Bridge (Marco Polo Bridge)
- 类别: 桥梁
- 年代: 金
- 建造/形成年代: 1189-1192
- 地点: 北京市丰台区

## 建筑特点
- 多孔石拱桥，桥身由多个石拱跨组成，适应河道宽度与水位变化
- 栏板与望柱上常见石狮雕刻（“卢沟桥石狮”）
- 桥面线形平缓，整体比例修长

## 历史背景
- 卢沟桥是北京地区重要的古代交通节点之一，长期承担跨河通行功能
- 在中外旅行记述中也较为知名（“Marco Polo Bridge”）

## 识别要点（用于AI识别）
- 连续多孔拱跨形成的节奏
- 栏杆望柱与石狮群的重复纹理
- 长桥横跨河道的低矮轮廓
