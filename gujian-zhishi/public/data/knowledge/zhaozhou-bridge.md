# 赵州桥（安济桥）

- ID: zhaozhou-bridge
- 英文名: Zhaozhou Bridge (Anji Bridge)
- 类别: 桥梁
- 年代: 隋
- 建造/形成年代: 595-605
- 地点: 河北省石家庄市赵县

## 建筑特点
- 单孔敞肩石拱：主拱两侧设置敞肩小拱，减轻自重并利于泄洪
- 石砌拱券与桥面铺装形成整体受力体系
- 结构简洁但工程创新显著，具有较强的形态辨识度

## 历史背景
- 赵州桥常被视为中国古代桥梁工程的代表性作品之一
- 其敞肩设计影响了后世石拱桥的结构优化思路

## 识别要点（用于AI识别）
- 单孔大拱 + 两侧小拱的组合特征
- 石材纹理与拱圈线条
- 桥拱与水面/河岸形成的稳定几何关系
