## 1. 项目概述

### 1.1 项目简介

**古建智识** 是一款面向中国古代建筑的智能识别与可视化系统，通过多模态AI技术实现：

- 📸 **智能识别**：上传建筑图片，AI自动识别类型、年代、风格
- 🏛️ **3D展示**：沉浸式三维可视化体验
- 📚 **知识讲解**：RAG检索增强生成的专业知识
- ⚖️ **对比分析**：多建筑横向对比

### 1.2 核心数据

系统包含 **20座** 中国古代建筑的完整数据：

| 类别 | 数量 | 代表建筑 |
|-----|------|---------|
| 🏠 民居 | 4座 | 福建土楼、北京四合院、陕西窑洞、开平碉楼 |
| 🏛️ 官府 | 4座 | 直隶总督署、内乡县衙、平遥县衙、丽江木府 |
| 👑 皇宫 | 4座 | 故宫太和殿、故宫乾清宫、故宫午门、沈阳大政殿 |
| 🌉 桥梁 | 5座 | 赵州桥、卢沟桥、广济桥、安平桥、五亭桥 |

### 1.3 项目信息

- **赛事**：2026年中国大学生计算机设计大赛（4C）
- **赛道**：(6) AI+信息可视化设计
- **主题**：中国古代建筑成就——中华优秀传统文化系列之六
- **决赛**：济南 → 青岛（2026.8.11-15）

### 3.1 智能识别模块

#### 功能流程

```
用户上传图片 → AI识别处理 → 结果展示 → 保存历史
     │              │            │          │
     ▼              ▼            ▼          ▼
  支持拖拽      GLM-4V API    卡片展示    IndexedDB
  点击上传      多模态分析    置信度显示   本地存储
```

#### 识别维度

| 识别项 | 说明 | 示例 |
|-------|------|------|
| 建筑名称 | 具体建筑名称 | 故宫太和殿 |
| 建筑类别 | 民居/官府/皇宫/桥梁/其他 | 皇宫 |
| 所属朝代 | 建筑年代 | 明清 |
| 建造年份 | 具体年份 | 1420年 |
| 地理位置 | 所在地点 | 北京 |
| 建筑特点 | 特征列表 | 重檐庑殿顶、黄色琉璃瓦、和玺彩画 |
| 置信度 | AI识别可信度 | 95% |

```

  "location": "所在地点",
  "features": ["建筑特点1", "建筑特点2"],
```

### 4.2 核心数据类型

```typescript
// 识别结果
interface RecognitionResult {
  name: string;                    // 建筑名称
  category: '民居' | '官府' | '皇宫' | '桥梁' | '其他';
  era: string;                     // 所属朝代
  year: string;                    // 建造年代
  location: string;                // 所在地点
  features: string[];              // 建筑特点
  description: string;             // 详细描述

// 建筑数据
interface Building {
  id: string;
  name: string;
  category: string;
  era: string;
  year: string;
  location: string;
  coordinates: [number, number];
  features: string[];
  images: string[];
  description: string;
  culturalValue: string;
}

// 数据库记录
interface RecognitionHistory {
  id?: number;
  timestamp: number;
  result: RecognitionResult;
  imageCount: number;
  notes?: string;
}

interface FavoriteBuilding {
  id?: number;
  buildingId: string;
  name: string;
  category: string;
  addedAt: number;
}

interface DiseaseRecord {
  id?: number;
  buildingId: string;
  buildingName: string;
  diseaseType: string;
  severity: '轻微' | '中度' | '严重';
  position: string;
  description: string;
  recordedAt: number;
}
```

## 5. 数据设计

### 5.1 客户端数据库

使用 **Dexie**（IndexedDB封装）存储：

```typescript
class GujianDatabase extends Dexie {
  recognitionHistory!: Table<RecognitionHistory>;
  favoriteBuildings!: Table<FavoriteBuilding>;
  diseaseRecords!: Table<DiseaseRecord>;
  comparisonGroups!: Table<ComparisonGroup>;
  settings!: Table<UserSettings>;

  constructor() {
    super('GujianZhishiDB');
    
    this.version(1).stores({
      recognitionHistory: '++id, timestamp, [result.category]',
      favoriteBuildings: '++id, buildingId, category, addedAt',
      diseaseRecords: '++id, buildingId, diseaseType, severity, recordedAt',
      comparisonGroups: '++id, name, createdAt',
      settings: '++id, key, updatedAt'
    });
  }
}
```

## 6. 部署运行

### 6.1 环境要求

- **Node.js**: >= 18.0.0
- **npm**: >= 9.0.0
- **浏览器**: Chrome 90+, Firefox 88+, Edge 90+
- **WebGL**: 支持 WebGL 2.0

### 6.2 快速开始

#### 1. 安装依赖

```bash
npm install
```

#### 2. 配置环境变量

创建 `.env` 文件：
```
VITE_ZHIPU_API_KEY=your_api_key_here
```

#### 3. 启动开发服务器

```bash
npm run dev
```
访问 http://localhost:5173

### 6.3 常用命令

| 命令 | 说明 |
|-----|------|
| `npm run dev` | 启动开发服务器 |
| `npm run build` | 生产构建 |
| `npm run preview` | 预览构建产物 |
| `npm run test:e2e` | 运行E2E测试 |
| `npm run lint` | 代码检查 |

### 6.4 部署方式

#### 方式一：静态托管（推荐）

```bash
npm run build
# 将 dist/ 目录部署到 Vercel/Netlify/GitHub Pages
```

#### 方式二：桌面应用

```bash
npm run dist
# 生成 release/古建智识 Setup 1.0.0.exe
```

#### 方式三：Docker

```dockerfile
FROM node:18-alpine AS builder
WORKDIR /app
COPY . .
RUN npm install && npm run build

FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
```
