# 古建智识——多模态AI驱动的中国古代建筑3D可视化系统

> 🏛️ 探索中国古代建筑之美，AI赋能文化遗产传承
> 
> 2026年中国大学生计算机设计大赛参赛作品 | AI+信息可视化设计赛道

## ✨ 功能特点

### 🤖 智能识别
- 上传古建筑图片，AI自动识别建筑类型、年代、风格
- 支持民居、官府、皇宫、桥梁四大类别
- 基于智谱清言GLM-4V多模态大模型（大赛指定国产AI）

### 🏛️ 3D可视化
- Three.js + WebGPU 高性能渲染
- 沉浸式3D建筑浏览体验
- 支持旋转、缩放、细节查看

### 📚 知识图谱
- RAG检索增强生成
- 专业的建筑知识讲解
- 历史背景、结构特色、文化价值

### ⚖️ 对比分析
- 多建筑横向对比
- 可视化数据分析
- 特征差异一目了然

## 🚀 快速开始

### 环境要求
- Node.js >= 18.0.0
- npm >= 9.0.0

### 安装运行

```bash
# 安装依赖
npm install

# 配置环境变量
echo "VITE_ZHIPU_API_KEY=your_api_key" > .env

# 启动开发服务器
npm run dev

# 访问 http://localhost:5173
```

### 构建与测试

```bash
# 生产构建
npm run build

# 运行E2E测试
npm run test:e2e

# 查看测试报告
npm run test:e2e:report
```

## 🛠️ 技术栈

| 类别 | 技术 |
|------|------|
| 前端框架 | React 19 + TypeScript 5.9 |
| 构建工具 | Vite 7 |
| 3D渲染 | Three.js + @react-three/fiber |
| 样式框架 | Tailwind CSS |
| 动画效果 | Framer Motion |
| AI服务 | 智谱清言 GLM-4V |
| 测试工具 | Playwright |

## 🏗️ 建筑数据

本项目包含20个中国古代建筑的完整数据：

- **民居**: 福建土楼、北京四合院、陕西窑洞、开平碉楼
- **官府**: 直隶总督署、内乡县衙、平遥县衙、丽江木府
- **皇宫**: 故宫太和殿、故宫乾清宫、故宫午门、沈阳大政殿
- **桥梁**: 赵州桥、卢沟桥、广济桥、安平桥、五亭桥
