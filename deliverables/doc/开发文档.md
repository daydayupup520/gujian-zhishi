## 1. 快速开始

### 1.1 环境准备

确保已安装：
- ✅ Node.js >= 18.0.0
- ✅ npm >= 9.0.0
- ✅ Git

### 1.2 安装步骤

```bash
# 1. 进入项目目录
cd E:\vs code\qqq\gujian-zhishi

# 2. 安装依赖
npm install

# 3. 配置API密钥
echo "VITE_ZHIPU_API_KEY=your_api_key" > .env

# 4. 启动开发服务器
npm run dev

# 5. 打开浏览器访问 http://localhost:5173
```

### 1.3 首次运行检查清单

- [ ] 依赖安装完成（无报错）
- [ ] `.env` 文件已创建并配置API密钥
- [ ] 开发服务器成功启动（端口5173）
- [ ] 浏览器能正常访问首页
- [ ] 图片上传功能正常
- [ ] AI识别功能返回结果（需联网）

## 3. 功能模块详解

### 3.1 智能识别模块

**文件位置**: `src/pages/DiagnosisPage.tsx`

**核心组件**:
- `ImageUploader` - 图片上传组件
- `RecognitionResult` - 识别结果展示

**工作流程**:
```
1. 用户上传图片 → ImageUploader
2. 图片转Base64 → fileToBase64()
3. 调用AI接口 → zhipu.recognize()
4. 解析JSON结果 → parseRecognitionResult()
5. 展示结果 → RecognitionResult
6. 保存历史 → database.recognitionHistory.add()
```

**关键代码**:
```typescript
// 调用AI识别
const recognizeBuilding = async (imageBase64: string) => {
  const response = await fetch('https://open.bigmodel.cn/api/paas/v4/chat/completions', {
    method: 'POST',
    headers: {
      'Authorization': `Bearer ${API_KEY}`,
      'Content-Type': 'application/json'
    },
    body: JSON.stringify({
      model: 'glm-4v',
      messages: [
        {
          role: 'user',
          content: [
            { type: 'text', text: PROMPT },
            { type: 'image_url', image_url: { url: imageBase64 } }
          ]
        }
      ]
    })
  });
  
  const data = await response.json();
  return JSON.parse(data.choices[0].message.content);
};
```

### 3.2 3D可视化模块

**文件位置**: `src/components/features/Scene3D.tsx`

**技术栈**: Three.js + @react-three/fiber

**核心功能**:
- 3D模型加载（GLTF/GLB）
- 场景光照（环境光+定向光+点光源）
- 相机控制（旋转、缩放、平移）
- 交互检测（Raycaster点击检测）

**使用示例**:
```typescript
import { Canvas } from '@react-three/fiber';
import { OrbitControls, Environment } from '@react-three/drei';

const Scene3D = () => {
  return (
    <Canvas camera={{ position: [0, 0, 5] }}>
      <Environment preset="city" />
      <ambientLight intensity={0.5} />
      <directionalLight position={[10, 10, 5]} />
      <Model />
      <OrbitControls />
    </Canvas>
  );
};
```

## 4. 开发规范

### 4.1 命名规范

| 类型 | 命名方式 | 示例 |
|-----|---------|------|
| 组件文件 | PascalCase | `ImageUploader.tsx` |
| 工具函数 | camelCase | `fileToBase64.ts` |
| 常量 | UPPER_SNAKE_CASE | `MAX_FILE_SIZE` |
| 类型/接口 | PascalCase | `RecognitionResult` |
| CSS类名 | kebab-case | `image-uploader` |

### 4.2 组件规范

```typescript
// ✅ 推荐写法
import React from 'react';

interface Props {
  title: string;
  onSubmit: (data: FormData) => void;
}

export const MyComponent: React.FC<Props> = ({ title, onSubmit }) => {
  const [count, setCount] = React.useState(0);
  
  const handleClick = React.useCallback(() => {
    setCount(c => c + 1);
  }, []);
  
  return (
    <div className="my-component">
      <h1>{title}</h1>
      <button onClick={handleClick}>Count: {count}</button>
    </div>
  );
};
```

### 4.3 提交规范

```
feat: 新增功能
fix: 修复bug
docs: 文档更新
style: 代码格式（不影响功能）
refactor: 重构（既不是新增也不是修复）
test: 测试相关
chore: 构建过程或辅助工具的变动
```

**示例**:
```bash
git commit -m "feat: 添加图片批量上传功能"
git commit -m "fix: 修复3D场景内存泄漏"
git commit -m "docs: 更新API文档"
```

## 5. 常见问题

### Q1: 安装依赖报错？

**A**: 尝试以下步骤：
```bash
# 清除缓存
npm cache clean --force

# 删除node_modules
rm -rf node_modules

# 重新安装
npm install
```

### Q2: AI识别不工作？

**A**: 检查以下几点：
- ✅ `.env` 文件已创建
- ✅ `VITE_ZHIPU_API_KEY` 已设置且有效
- ✅ 网络连接正常
- ✅ 浏览器控制台无CORS错误

### Q3: 3D场景显示空白？

**A**: 
- 检查浏览器是否支持WebGL 2.0
- 检查模型文件是否存在
- 查看控制台错误信息

### Q4: 如何添加新建筑数据？

**A**:
1. 添加图片到 `public/data/images/`
2. 编辑 `public/data/buildings.json`
3. 可选：添加知识文档到 `public/data/knowledge/`

### Q5: 如何构建生产版本？

**A**:
```bash
# 构建
npm run build

# 预览
npm run preview

# 构建产物在 dist/ 目录
```
